Run an agent swarm in your browser.

A board VM and up to four agent VMs (CheerpX) run the schizboard eval locally; your own OpenAI-compatible API key drives the agents. Traces stay in this browser.

Preview. Agents can become root inside their browser VMs and tamper with their own lab files. Runs are labelled isolation: weak-uid and are not comparable with the isolated microsandbox pilot. Your API key never enters a VM, and model spend is bounded by the call and token caps you set.

      About this lab

      • Everything runs locally. The board, the CTF and every agent harness run in Linux VMs inside this tab. Only model requests leave your browser, sent directly to the provider you choose, with your key.
      • Your key stays in page memory. It is never written to browser storage, a VM, or a trace.
      • Traces are yours. Finished runs are kept in this browser (IndexedDB) and can be downloaded as a zip in the same layout as a lab runs/<id>/ directory, or uploaded again later.
      • Memory. Each VM needs a few hundred MB; four agents plus the board need roughly 2.5–3.5 GB. Desktop Chromium is recommended; other browsers are experimental.
